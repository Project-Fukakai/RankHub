# RankHub 一站式音游聚合平台
一款 App 管理多款音游与平台账号，同步你的游戏数据与成绩，随时查看自己的成长与记录；借助 RankHub NET，将数据带到云端，与其他玩家分享成绩、交流想法，让每一次游玩都留下值得回看的记录。

该项目目前已经闭源，未来有可能会在合适的时机开放部分源代码，RankHub 使用的部分技术已经在 [Project Fukakai](https://github.com/Project-Fukakai) 中开源。

闭源前的代码仍保持开源，位于 「[old](https://github.com/Project-Fukakai/RankHub/tree/old)」和「[archive](https://github.com/Project-Fukakai/RankHub/tree/archive)」分支中，使用 MIT 协议授权。与此同时，我们也欢迎拥有相关经验的开发者能够加入我们，邮箱： join@rankhub.cc
